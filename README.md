# Unstop_Hackathon

An AI assistant that remembers user conversations using memory system + Gemini API.

This project solves the biggest problem in normal chatbots:
👉 They forget conversations  
👉 Our AI remembers everything

So it becomes a *personal intelligent assistant*.

---

# 🚀 Features
- Remembers user information
- Smart conversation using Gemini API
- Stores memory in files
- Uses past memory in future chats
- Beginner friendly + hackathon ready

---

# 🛠️ Technologies Used
- Python
- Google Gemini API
- File-based memory system
- VS Code
- Git Hub

- SETUP INSTRUCTIONS

- 1. Install Python from https://www.python.org/downloads/ --version 3.14.3
 
  2. Clone project: git clone https://github.com/nakharevatsal/unstop_hackathon.git
 
  3. Install requirnments:
      - open terminal is project folder
      - pip install -r requirnments.txt
        
  4. Open app.py
 
  5. Find this line: client = genai.Client(api_key="Your_GEMINI_API_key")
     - paste your gemini key in place of "Your_GEMINI_API_key"
    
  6. Save file
 
  7. Run the file (python app.py)
